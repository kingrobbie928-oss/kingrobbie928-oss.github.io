1 · The problem

Powerful, but unattractive and overwhelming

BitTorrent clients are powerful but look like spreadsheets from 2005. Existing clients look bad. They are grey, cramped and visually dated, with no attention paid to aesthetics. They also expose the whole engine at once and it is full of rarely used settings. With no visual hierarchy, the few things people actually check up on are lost among others they never even touch. It still works, but has a high cognitive load.

  1. Unattractive by defaultToo much information, options and colors in all the wrong places.
  2. No HierarchyEvery column and every number at the same visual weight.
  3. Information OverloadRSS, search plugins, web UI and a dozen other features crowd out the one job people came to do.
  4. Colour ConfusionThere are often multiple colours in a single row.
2 · Principles Followed

3 rules every screen is checked against

Each one is a rule I could check a screen with, with a real example from the app.

Reduce

Cutting down things so that there are fewer options and lesser things to scan.

Example

RSS, search plugins, Web UI, scripting and tags were removed from the product, not hidden in a menu.

Prioritise

The main task at hand gets a higher priority and the rest follow.

Example

Every row leads with name, progress and status. Speeds, ETA and ratio are muted.

Visual Cues

Colour means status, but it is never the only cue.

Example

Each state has a colour, an icon and a label, so it still reads in greyscale.

3 · The solution

A calm, focused client that shows only what matters

I designed for calm. The interface is reduced to the everyday job, given a clear visual hierarchy, and colour carries meaning instead of decoration. Power stays one click away through progressive disclosure, never in the way.

4 · The visual language

One set of tokens and one meaning per colour

The switches, status colours, progress bars and the speed graph all follow the same colour system from a single token file.

4.1 · The four symbols

One switch for light and one for colour

Dark

A crescent moon. Activates dark mode.

Light

A sun with rays. Activates light mode.

Normal

A single grey dot. Default mode for a simple interface.

Vibrant

Four colourful dots. Activates vibrant mode.

4.2 · Status Bar

The Nine status colours

Through the status bar you can filter the kind of torrents that you wish to see and they follow the same color system as the progress bars.

  • All torrents
  • Downloading
  • Seeding
  • Completed
  • Paused
  • Queued
  • Checking
  • Stalled
  • Error

4.4 · Tracking Speed

One small card answers your “is it actually moving?”

Pinned to the bottom of the sidebar, the speed card shows both upload and download speed together. Upload and download colours follow the colour system.

5 · Visual identity

A mark and a home for the brand

The wordmark carries the strength aspect of the product and the website gives it a home on the web.

5.1 · Logo

A calm interface with a strong logo

RoTorrent is a calmer and stronger torrent client. The interface carries the calm and the logo carries the strength. It has a strong metallic and edgy feel to it. The O's are split into fragments, a symbol of how torrents work. They are built as opposites on purpose as it provides a nice contrast and that contrast conveys why rotorrent was built.

5.2 · Website

RoTorrent lives online too

The site follows the system theme, with a toggle in the corner and shows the app in all four looks. It was made to look calm with the wave effect for the reasons discussed above.

6 · The outcome

Same power but calmer

A complete client running on a real libtorrent engine, with a calm interface and one visual language from the title bar to the last dialog.
